# employee-mgmt-ms
This the backend service for employee management

## Technologies Used
- Java 23
- Spring Boot 3.4.0
- Spring Data JPA 
- Hibernate
- PostgreSQL
- Liquibase
- Kafka
- Docker
- Vault

## Work flow
- The application exposes REST APIs to perform CRUD operations on employee data.
- It uses Spring Data JPA and Hibernate to interact with a PostgreSQL database.
- Liquibase is used for database schema management and versioning.
- Kafka is used for messaging and event-driven communication. 
- Docker is used to containerize the application for easy deployment.
- Vault is used for managing secrets and sensitive configuration data.
- The application is built using Gradle for dependency management and build automation.
